# Site Photography

`wuhan-yuejiazui-960.webp` and `wuhan-yuejiazui-1920.webp` are resized WebP
versions of **Yuejiazui Junction Wuhan Skyline**, photographed by **Nkon21**
on 27 May 2023.

- Source: https://commons.wikimedia.org/wiki/File:Yuejiazui_Junction_Wuhan_Skyline.jpg
- License: https://creativecommons.org/licenses/by/4.0/
- Changes: resized and encoded as WebP; CSS crops the image to fit each viewport.
- No buildings, roads, colors, or geographical content have been generated or redrawn.

The Yuejiazui photograph is used on the language-entry page.

`wuhan-yezhihu-960.webp` and `wuhan-yezhihu-1920.webp` are resized WebP
versions of **Yezhihu Lake in Wuhan**, photographed by **Arnie97** on
12 May 2019, used on the Chinese and English home pages.

- Source: https://commons.wikimedia.org/wiki/File:Yezhihu_Lake_in_Wuhan.jpg
- License: https://creativecommons.org/licenses/by-sa/4.0/
- Changes: resized and encoded as WebP; responsive CSS cropping and a contrast overlay.
- These image adaptations remain licensed under CC BY-SA 4.0.
- No geographical features have been generated, removed or redrawn.

Both photographs have visible source and license credits. They are contextual
imagery, not research results. The lakefront view is not an aerial photograph.

The site uses a self-hosted subset of Noto Sans SC from Google Fonts, under the
SIL Open Font License. The license is distributed beside the font at
`assets/webfonts/utsi/OFL.txt`. Rebuild the assets using
`scripts/prepare-site-assets.py` with the source photograph, the Noto Sans SC
variable TTF and its OFL file. This requires Pillow, fonttools and brotli.
