# 首页设计审查与优化

审查日期：2026-09-29。对象：[中文线上首页](https://yangyi-wu.github.io/zh/)，并检查共享的英文首页与导航。修改基于本地提交 `177a4f1`；审查使用实际浏览器页面，搜索引擎缓存仍显示旧版个人主页，不作为视觉依据。

## 设计判断

网站已有清楚的课题组定位、真实城市照片、研究原图及完整论文入口。主要不足在信息呈现：首屏行动入口不够明显；三个研究方向纵向展开，占用了较多滚动空间；长摘要和图文对齐削弱了研究成果的可读性。此次保留原有学术风格、资料和页面结构，优先改善层级、阅读路径及移动体验。

## 问题与已完成的调整

| 优先级 | 审查发现 | 调整 |
| --- | --- | --- |
| 高 | 首屏只有一个较弱的下划线入口，研究成果需要向下寻找。 | 设置“探索研究方向”主按钮与“精选研究成果”次入口；保持 48px 点击高度。 |
| 高 | 研究主线采用三个连续的大横向区块，阅读路径偏长，不便并列理解。 | 宽屏改为三个等宽栏目；平板采用横向信息行；手机保留单栏。修正分隔线占用栏宽的问题。 |
| 高 | 论文摘要先铺背景，手机上图表出现较晚。 | 中英文摘要改为先呈现研究发现，再交代案例和意义。完整研究内容仍可通过论文页面查看。 |
| 中 | 图文垂直居中，让论文标题上方出现明显空白；自动均衡换行会拆开中文词组。 | 论文文字与图表顶部对齐，中文标题按主题与说明分行，避免“可达性”被拆开。 |
| 中 | 原图入口只有放大图标，含义不够直观。 | 增加可见的“查看原图”文字，并为读屏提供包含论文题目及新标签页提示的名称。 |
| 中 | 固定首屏高度不利于容纳不同语言和放大的文字。 | 首屏改为随内容增长，设置最小高度；手机按钮允许换行。 |
| 中 | 手机菜单的源代码顺序与视觉顺序不一致，且没有跳过导航的入口。 | 菜单按钮移到常驻链接之后，增加“跳至主要内容”以及可接收焦点的正文区域。 |
| 中 | 招生联系区和普通正文缺少区分，页脚分成多条零散信息。 | 联系区使用低对比底色；页脚集中辅助链接，分开版权、更新时间和技术来源。 |

## 验证记录

- Jekyll 构建通过；现有双语页面、论文内容、内部链接、图片预算与脚本校验通过。
- 语言行为、论文筛选、导航共 15 项现有测试通过。
- 中英文首页分别检查 320、390、768、960、1024、1440px 宽度，正文与导航均未发现横向溢出。
- 实际检查手机菜单开关、Esc 关闭并返回菜单按钮、中英文切换、首屏两个锚点，以及跳转正文后的焦点。
- 检查浅色与深色模式、研究原图加载、论文标题换行、研究区等宽对齐。浏览器预览未记录错误或警告。
- 保留所有论文数据、作者身份、招生年份、原图来源与照片许可。未添加未经核实的学术动态。
